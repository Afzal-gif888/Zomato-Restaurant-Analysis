# Zomato Restaurant Data Analysis

## Project Overview
This project analyzes the Zomato restaurant dataset to extract insights on restaurant ratings, cuisines, locations, pricing, and customer preferences.

## Objective
- Analyze restaurant ratings and trends
- Identify popular cuisines
- Discover restaurant hotspots
- Study price vs rating relationships
- Generate business recommendations

## Data Cleaning
- Removed duplicates
- Handled missing values
- Fixed rating values
- Converted cost columns to numeric format

## Analysis Performed
- Rating Distribution Analysis
- Location Hotspot Analysis
- Popular Cuisine Analysis
- Price vs Rating Analysis
- Online Order Analysis
- Table Booking Analysis
- Correlation Analysis

## Visualizations
All charts and screenshots are available in the repository.

## Key Findings
1. Most restaurants have ratings between 3.5 and 4.2.
2. North Indian cuisine is the most popular.
3. BTM, Whitefield, and HSR are major restaurant hotspots.
4. Higher price does not guarantee higher ratings.
5. Ratings and votes show positive correlation.

## Business Recommendations
1. Partner with top-rated restaurants.
2. Develop cuisine recommendation systems.
3. Use ratings for personalized suggestions.
4. Promote trending cuisines and hotspots.
5. Build pricing intelligence dashboards.
